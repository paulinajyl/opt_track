# OPT Application Tracker 
Hi! This is a Telegram bot deployed on Fly.io that helps consolidate and track everyone's OPT applications.
Instead of searching through the chat history to look for who applied for OPT on the same date as you, who applied for premium processing, or when someone got approved, you can now just chat with the bot to find out the information you need. This way, all the application details are in one place, and we can easily share updates without bogging down our group chat.

## Commands
`/help`: shows a list of commands you can use

`/start`: begins the process of adding your application details

`/add`: directly add your application to the database

`/clear`: delete your application details from the database

`/cancel`: stop the process of adding your application to the database (while doing `/add`)

`/track`: see a list of all the applications


## Running the app locally

```
python  src/main.py 
```
